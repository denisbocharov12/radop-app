# Отчёт по изменениям ветки `storefront-redesign`

Сравнение с `origin/master` на 2026-10-02. Всего **145 файлов, +12 175 / −5 916 строк**
(из них 24 файла — собранные ассеты в `public/build`).

## Чего ветка НЕ трогает

- `resources/views/v2/**` и остальные экраны админки — изменений нет.
- `routes/v1/**` (админские маршруты), сидеры прав, роли — изменений нет.
- Контроллеры админки — изменён один файл в `app/Http/Controllers/v1/`: `MegaMenuController.php`,
  и это API меню, из которого витрина берёт каталог (правка на устойчивость к пустым данным, интерфейс админки не затронут).
- Миграции и схема базы — не менялись.

## На что смотреть при слиянии в `master`

1. Правка процента скидки в `ThemeProductManager` влияет и на старые шаблоны — там бейдж тоже станет корректным.
2. `routes/web.php` содержит правило подмены картинок **только для `local`**; на боевом сервере оно не включится,
   но строку `STOREFRONT_MEDIA_FALLBACK_URL` в прод-окружение добавлять не нужно.
3. Сборка витрины отдельная: при деплое нужен `npm run build` (файлы `public/build` в репозитории уже обновлены).
4. Админка не затронута, миграции не добавлялись — откат ветки не требует изменений в базе.
