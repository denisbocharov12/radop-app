# Секции главной страницы — как пользоваться

Главная собирается из строк таблицы `home_sections`, а не из шаблона: порядок
блоков, их видимость и состав правятся в админке, без выката.

Раздел: **Контент → Секции главной** (`/admin/home-sections`).

## Что можно сделать

- **Поменять порядок** — перетащить строку в списке. Порядок сохраняется сразу.
- **Спрятать блок** — снять галочку «Показывать на сайте». Блок исчезает с
  главной, настройки остаются.
- **Добавить ленту товаров** — выбрать, откуда брать товары: новинки, хиты,
  со скидкой, любое условие товара из номенклатуры (`winter`, `hot`, `featured`…)
  или перечислить коды 1С вручную.
- **Добавить секцию «Сезонные новинки»** — то же, что лента, плюс фоновое фото,
  цветная маска поверх него и светлый заголовок.

Пустая лента на сайт не выводится: заголовок без товаров выглядит сбоем. Если
секция настроена, но не видна — проверьте, есть ли товары по выбранному условию.

## Поля

| Поле | Зачем |
|---|---|
| Тип секции | баннеры, топ-категории, лента товаров, сезонные новинки, бренды |
| Порядок | меньше — выше. Меняется и перетаскиванием |
| Заголовок (ro/ru) | подпись блока. Пустой перевод подменяется румынским |
| Подпись | необязательная строка под заголовком |
| Ссылка «Смотреть все» | например `/shop/new` |
| Показывать на сайте | видимость |

Для топ-категорий дополнительно:

| Поле | Зачем |
|---|---|
| Коды разделов 1С | какие разделы показывать и в каком порядке |

Топ-категории — это полоса быстрых входов в каталог под баннером: компактные
блоки «иконка + название», без заголовка секции. Прежняя полоса меню под
шапкой витрины убрана, её настройки в разделе «Шапка-меню» остались на месте.
На десктопе блоки всегда в одну строку, поэтому разделов берётся не больше
восьми (`HomeSectionController::MAX_TOP_CATEGORIES`) — лишние коды не выводятся.
Иконка берётся из медиафайла раздела, без него рисуется стандартный значок.
Для лент и сезонной секции дополнительно:

| Поле | Зачем |
|---|---|
| Откуда брать | источник товаров |
| Сколько показывать | ограничение, по умолчанию 12 |
| Коды товаров 1С | только для «выбранных вручную», порядок сохраняется |

Для сезонной секции:

| Поле | Зачем |
|---|---|
| Фоновое фото | растягивается на всю ширину секции |
| Цвет маски | сплошной слой поверх фото |
| Прозрачность маски | 0 — фото как есть, 100 — сплошной цвет. По умолчанию 55 |
| Заголовок | светлый (на тёмном фоне) или тёмный (на светлом) |

Карточки товаров остаются на белом фоне — маска сквозь них не просвечивает.

## Как это устроено внутри

- Таблица `home_sections`: тип, переводимые заголовки, ссылка, порядок,
  видимость и настройки типа (JSON). Фон — медиатека, коллекция
  `home_section_background`, по одному файлу на секцию.
- `App\Services\Home\HomeSectionsRenderer` отдаёт готовые секции с товарами,
  фоном и заголовком на текущем языке.
- Шаблоны секций: `resources/views/frontend/v1/pages/home/sections/*.blade.php`
  (имя файла = тип секции).
- Выборки товаров кешируются на два часа; после сохранения секции кеш чистится.
- Миграция создаёт пять строк, повторяющих нынешнюю главную, поэтому выкат
  ничего не меняет визуально.

## Если понадобится новый тип секции

1. Добавить константу и подпись в `App\Models\HomeSection::types()`.
2. Положить шаблон `sections/<тип>.blade.php`.
3. При необходимости — свои поля в форме админки и разбор в
   `HomeSectionController::payload()`.
