## Что уже сделано

### Синхронизация с master (ветка `storefront-redesign`)

24 коммита, все по витрине и SEO, ни одного файла админки:
canonical-редиректы (`/ro`, `/index.php`, слеш в конце — один 301),
`noindex` для служебных параметров, hreflang через `LocaleUrl`,
JSON-LD `Product`/`Offer`/`BreadcrumbList`/`OnlineStore`, robots.txt, карта сайта.
Удалён `LocalizationPermanentRedirect` — на master его заменил `CanonicalPathRedirect`.

### Первая партия по ТЗ (ветка `storefront-tz-v9.1`)

Пункты 1–3, 7, 12–13, 18–19, 26, 28–29, 34, 65–66 — типографика (Roboto + Aptos Narrow),
контраст серого, бренд в карточке, подписи выгрузки, строка «В наличии», пустое описание.
Плюс из переписки: «−» превращается в удаление на минимальном количестве
и исправлена ошибка 500 при удалении позиции из корзины.
